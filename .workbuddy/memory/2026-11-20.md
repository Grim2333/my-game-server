# 2026-11-20 工作日志

## 新增规则：每人手牌上限 8 张
- 新增常量 `HAND_LIMIT = 8` 与统一守卫 `canGainCard(sessionId)`（`hand.length < 8` 才允许获得新牌）。
- **覆盖的「净增手牌」入口**（全部加判断）：
  - `initGame` 发初始手牌：`while` 加 `hand.length < HAND_LIMIT`；超出的牌 `deck.push` 退回牌库（不丢牌）。
  - `drawCard()`：守卫放在 `deck.shift()` **之前**，满 8 张返回 null 且**不消耗牌库**。此方法是核心，平静回合发牌、天使重生摸牌、测试消息都走它。
  - `replenishHands()`：循环内 `if (!canGainCard(id)) break`。
  - 从墓地获得牌的 3 个技能：`necromancer` / `breedWolf` / `witchRevive` —— 满 8 张时**不 splice、牌留墓地**，技能结算流程照常走完（不卡 pendingAction），给一条 hint。
- **明确不覆盖**（不是「获得新牌」，强加会丢牌/破坏等量交换）：牌归位（`returnCardToHand`）、白痴放回原位、盗贼交换（一进一出净 0）、丘比特链接等。
- 天使重生日志修正：`drawCard` 返回 null 时区分「牌库已空」/「手牌已达上限」，避免误导。
