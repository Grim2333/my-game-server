## 2026-10-22 第三阶段：战场 + 胜负判定 + 昼夜限制 + 狼刀

## 2026-10-22 第四阶段：死亡结算队列 + 技能引擎
- 核心机制：MyRoom 新增 deathQueue: DeathEvent[]（服务端私有）。所有掉牌行为走 pushDeath() 入队 → resolveQueue() 逐条解析；无技能牌直接进墓地，猎人/狼王死亡触发技设置 pendingAction 后 return【暂停队列】，玩家 chooseTarget 选完目标后恢复 → while 循环天然支持 A 死带 B、B 死带 C 级联
- 统一交互：pendingAction（嵌套 schema，type/actor/zone/description）取代旧 pendingSacrifice；chooseTarget { index } 统一消息（index=-1 跳过）；对方手牌不可见故按位置选
- 三张技能牌：猎人（死→开枪带对方一张）、狼王（type=wolf，死→带对方一张）、女巫（夜间 useSkill {cardId, mode: save|poison}，save 从自己墓地救回、poison 毒对方一张；女巫牌不消耗）
- 牌库改为 20 张：8 狼 + 6 民 + 2 猎人(god) + 2 狼王(wolf) + 2 女巫(god)；Card 新增 skill 字段
- 防御：无合法目标技能自动作废不卡队列；每次死亡后 checkGameOver（返回 boolean），game over 清空队列；onLeave 清队列+pending
- 测试 12 个全过（级联/自动作废/权限越界/女巫双模式/胜负）；真实服务器冒烟测试：猎人被刀→开枪、女巫毒药均通过
- public/index.html 重写：pendingAction 高亮选区（自己手牌/对方背面牌/自己墓地可点）、顶部脉冲横幅、跳过按钮、女巫模态框、快照 diff 无变化不重绘
