## 顺带修掉一个真实同步 Bug（重要）
保底后每次开局第 1 夜都会触发盗贼换牌，结果 mocha 里刷出
`"refId" not found`（基线 0 次 → 改动后 43 次）。

根因：`tryThiefSwap` 直接把同一个 Card Schema 实例从一个玩家的**私有手牌**搬到另一个玩家的私有手牌。
接收方从未收到该实例的结构补丁，解码时报 refId 丢失 —— 那张牌在对手屏幕上直接消失。

修复：跨玩家搬家一律用新实例。新增 `cloneCard(src, owner)` 拷贝全部字段
（id/name/type/skill/owner/acted/witchReviveUsed/witchPoisonUsed/thiefUsed），
换出时 `thiefUsed=true; skill=""; acted=false`，换入时 `acted=false`。
修复后 refId 警告回到 0 次。

> 教训：以后凡是「牌在两个玩家之间移动」（以后若加类似换牌/偷牌卡），
> 都必须 clone，不能搬同一个实例。

## 盗贼"用不了"的真因（第二轮反馈）
反馈："就算出现了盗贼我发现还是无法使用盗贼的技能"。
写临时诊断脚本（跑完即删）打印双方手牌，发现换牌其实**一直有触发**，
真正的问题是**先手截胡后手**：
- 保底后双方各持 1 张盗贼；P1 夜先手发动时，随机偷牌会偷到 P2 那张「还没发动」的盗贼；
- 于是 P2 整局轮不到自己的盗贼发动（P1 第 2 夜还拿着换来的盗贼又换了一次）；
- 后手玩家看到的就是：我的盗贼在我还没行动时就被换走，变成白板平民 → "技能用不了"。

修复（`MyRoom.tryThiefSwap`）：
- 选偷牌目标时【排除对手手上未发动的盗贼】(skill==='thief' && !thiefUsed)；
  对方只剩未发动盗贼时本夜推迟（打日志）。
- 交换后给双方定向发 `cardReturned`，让换进来的牌在画面上闪一下（原来只有折叠日志，玩家察觉不到）。
- hint 文案改写清楚："盗贼发动：你换来了「X」，你的盗贼已交给对手（此后是白板平民）"。
- `playCard` 里对「未发动盗贼」给专属拒绝文案（原来只会说"黑夜只能打出狼人牌"，很困惑）。

前端 `public/index.html`：
- `cardEl`：未发动的盗贼加金色胶囊角标 `🔀 入夜换牌`（发动后变白板平民，标记自然消失）。
  因为盗贼是被动技能、没有按钮，不给标记玩家完全不知道这张牌干嘛。

测试：保底用例补强 —— 走完第 1 夜两回合后，双方手上各应有且仅有 1 张
`thiefUsed=true && skill=""` 的盗贼（证明两人都真正发动过，没被截胡）。

## 盗贼改为【手动点击发动】（用户拍板）
用户选了"改成手动点击发动"。规则定型：
- 夜里点盗贼牌 → 立刻与对手随机换一张手牌（playCard 里新增盗贼分支 → tryThiefSwap(sessionId, index)）。
- 发动完**不结束回合**（resumeTurn 刷新倒计时），还能继续出别的牌。
- **不点也会兜底**：endTurn 里若 phase==='night' 且手上还有未发动盗贼 → 强制发动一次
  （保留"拿到盗贼的第一夜必定换牌"）。startTurn 里的自动触发已删除。
  超时/跳过/结束回合都走 endTurn，所以兜底覆盖全。
- 白天点盗贼 → 拒绝文案"盗贼只能在夜里发动"（原来只会说"黑夜只能打出狼人牌"）。

实现要点：`tryThiefSwap(sessionId, forceIndex = -1, auto = false): boolean`，
有返回值后 playCard 才能在失败时给出"对手没有可以交换的牌"。

前端：
- `usable` 增加 `isThief`（夜里 + 轮到我 + 未发动）→ 盗贼可点、会被 .playable 高亮。
- 角标 `🔀 夜·换牌` 只在该牌**当前点不了**时显示（能点时高亮已足够，避免冗余）。
- 点击日志区分：盗贼不 fly 到行动区、不写"你打出了 X → 行动区"，改"🔀 盗贼发动：与对手换一张手牌…"。

测试：新增「夜里点牌可主动发动，且不会自动结束回合」；
原「强制换牌」用例改为验证兜底路径（整夜不点，回合结束时自动换）。
全量 **44 passing**、refId 0 次、tsc 0 错误、前端脚本语法 OK、服务 HTTP 200。
