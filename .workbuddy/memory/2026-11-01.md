## 盗贼改为「出牌 → 选目标」两段式（用户重defined 技能形态）
用户描述的新流程：夜晚点盗贼 → **进自己的行动区** → **选对手一张手牌** → 那张归你、盗贼归对方且技能抹除（白板平民）。

服务端 `src/rooms/MyRoom.ts`：
- `PendingActionType` 新增 `"thiefSwap"`（MyState.ts 同步）。
- `playCard` 盗贼分支改为出牌流程：hand 移除 → push 到 `player.play`（行动区）→
  `setPendingAction("thiefSwap", actor, "opponentHand", "🔀 盗贼：选择对方一张手牌…")`。
  对手无手牌 → 直接拒绝，不进行动区。
- `chooseTarget` 新增 `case "thiefSwap"`：
  - 校验：目标存在 / 未被死亡锁定 / **不是对手尚未发动的盗贼**（否则对手永远轮不到自己的盗贼）。
  - 执行：偷来的牌 → clone 到我方手牌（插回盗贼原位，acted=false）；
    行动区的盗贼 → clone 到对手手牌，`thiefUsed=true; skill=""; acted=false`。
  - clone 的原因：跨玩家私有视图搬家必须用新实例，否则对手客户端 refId 丢失、牌直接不显示。
  - 结束后 `resumeTurn()`：**不停顿**，本回合还能继续用其它牌行动。
- 跳过（chooseTarget index -1）走通用分支 → 盗贼退回手牌，技能保留。

**兜底仍在**：`endTurn` 里夜间手上还有未发动盗贼 → 随机换一张（上一轮用户拍板的"不点也强制"）。
想取消就删 `endTurn` 里那一行。随机兜底仍遵守"不偷对手未发动盗贼"。

前端 `public/index.html`：
- `TARGET_ACTION.thiefSwap = "🔀 盗贼交换"`（对手手牌点击日志复用通用逻辑）。
- 点击盗贼不再特殊处理，与狼/神职一致走 `flyCard → my-play` 动画。

## 守卫自保漏洞：选目标没成功 / 超时，守卫本夜就没有自保

- 守卫自保不再混进 guarded（否则会污染"不能连续两晚守同一张"的 lastGuarded）。
- 明确取消守护（chooseTarget index=-1）时撤销自保；超时跳过则保留自保。rotateGuards / initGame 清空。
